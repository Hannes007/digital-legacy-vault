# module: rds-postgres

Encrypted, private PostgreSQL 16 (RDS) with credentials in Secrets Manager.

## Design notes
- **Encrypted at rest** with the provided CMK (storage + Performance Insights);
  `publicly_accessible = false` and the instance lives in the **isolated** subnet
  tier (invariant §7.1).
- **TLS enforced** — `rds.force_ssl = 1` in the parameter group; the connection
  URL in the secret uses `sslmode=require`.
- **No secrets in code/state inputs** — the master password is generated by
  `random_password` and written only to Secrets Manager (invariant §7.7).
- **Ingress** on 5432 is limited to `allowed_security_group_ids` (the EKS SG);
  the SG defines no egress (stateful return traffic only).
- **Multi-AZ** and **deletion_protection** are flags (on for staging/prod, off
  for dev). A timestamped final snapshot is taken unless `skip_final_snapshot`.

## Consuming the secret
Sync `credentials_secret_arn` into the cluster via External Secrets Operator; the
Helm chart references the resulting Kubernetes Secret (`DATABASE_URL`).

## Outputs
`address`, `endpoint`, `port`, `db_name`, `instance_arn`, `security_group_id`,
`credentials_secret_arn`.
