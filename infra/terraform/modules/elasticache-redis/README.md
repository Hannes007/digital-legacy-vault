# module: elasticache-redis

Encrypted Redis 7 replication group for sessions, cache, and BullMQ queues.

## Design notes
- **Transit + at-rest encryption both on** (invariant §7.1); at-rest uses the
  provided CMK.
- **AUTH token** is generated by `random_password` and stored only in Secrets
  Manager (invariant §7.7); the connection URL uses the `rediss://` (TLS) scheme.
- **Ingress** on 6379 limited to `allowed_security_group_ids` (EKS SG); the group
  sits in the isolated subnet tier.
- **HA**: `automatic_failover_enabled` + `multi_az_enabled` engage automatically
  when `num_cache_clusters > 1` (dev can run a single node to save cost).

## Consuming the secret
Sync `auth_secret_arn` into the cluster via External Secrets Operator; the Helm
chart references the resulting Kubernetes Secret (`REDIS_URL`).

## Outputs
`primary_endpoint_address`, `reader_endpoint_address`, `port`,
`security_group_id`, `auth_secret_arn`.
